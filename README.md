# CampusFlow: University Course Registration System

## Course
MIT 8103 — Advanced Database Systems  
Individual Practical Database Portfolio  
2026/2027 Academic Session

## Case Study
CampusFlow is a simulated university course registration system.
It will use synthetic data rather than real student records.

The database will support student records, departments, lecturers,
courses, academic terms, course offerings and student registrations.

## Database Users
- Registry staff maintain academic records and course offerings.
- Students register for courses and view their registrations.
- Lecturers view class lists and record grades.
- Database administrators manage database access and operations.

## Planned Operations
- Create student, lecturer, department and course records.
- Offer courses during specific academic terms.
- Register students without duplicate registrations.
- Prevent registration beyond a course offering's capacity.
- Record grades and retrieve academic records.
- Generate enrolment reports.

## Portfolio Structure
1. Database design and modelling.
2. Query processing and optimisation.
3. Transactions and concurrency.
4. NoSQL implementation.
5. Distributed and cloud database discussion.

## Planned Technologies
